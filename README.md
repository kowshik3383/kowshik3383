### What I build

- **Web platforms:** Next.js 15 / React 19 apps engineered for sub-second LCP, deterministic state, and high-conversion landing pages
- **Mobile products:** React Native + Expo apps with clean navigation, native gestures, and cross-platform release pipelines (EAS, App Store, Play Store)
- **Backend & data:** Node.js, NestJS, and Express services with type-safe schemas (Prisma), REST/WebSocket APIs, and RBAC-driven dashboards
- **Dev tooling:** offline compilers, MCP server auditors, and production-observability agents

### Selected production work

- **Tap Health — patient health flows:** shipped daily glucose tracking, meal logging, and multi-step onboarding in React, Next.js, and React Native; resolved navigation deadlocks, timezone bugs, and state-sync issues; shipped 30+ landing pages optimized for sub-second LCP; built Jest/Vitest/Playwright coverage for core patient flows
- **ZarvisGenix — doctor & HR platforms:** built scalable doctor portals, HR platforms, and admin dashboards with RBAC and real-time sync; integrated AI speech-to-text pipelines for voice transcription; pitched architecture directly to investors and stakeholders
- **AI Technical Interviewer:** voice-first assessment platform with real-time WebSocket keystroke streaming, Monaco Editor, multi-model fallback (Claude 3.5, GPT-4o, Gemini 2.5 Pro), and a deterministic FSM sandbox with automated scorecards
- **Figma to Code plugin — 1.5K+ installs:** 100% offline Figma Community plugin converting frames and Auto Layouts into HTML, Tailwind CSS, React JSX, and Next.js project exports

### Open source

- [**mcpdx**](https://github.com/kowshik3383/mcpdx) — completeness auditor & runtime linter for MCP servers; detects missing integration wiring, audits tool schemas/logs, and offers automated AST fixes. [Published on npm](https://www.npmjs.com/package/@valipireddykowshik/mcpdx) — 279 downloads
- [**figma-to-code-plugin**](https://github.com/kowshik3383/figma-to-code-plugin) — 1.5K+ installs. Generates production-ready HTML, Tailwind CSS, React, Svelte, and Styled Components from Figma designs, 100% private and offline
- [**production-monitoring-mcp**](https://github.com/kowshik3383/production-monitoring-mcp) — connects AI agents (Claude, Cursor, Antigravity) to real production observability, correlating Sentry, Vercel deploys, GitHub commit diffs, and Better Stack uptime in one command
- [**ai-interviewer**](https://github.com/kowshik3383/ai-interviewer) — adaptive technical interview simulator with a deterministic interview FSM, 9 language question banks, live coding sandbox, and voice hints
